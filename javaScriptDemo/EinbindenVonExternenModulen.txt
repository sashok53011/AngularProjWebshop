Einbinden von externen Modulen in 
JavaScript-Code, Node.js Version 24.12.0

Der Node Packet Manager npm wird dafür verwendet.
Eingabe im Terminal, wo sich die JS-Datei befindet. eventuell neuen Ordner mit mkdir erstellen
mkdir Projekt
Um das Einbinden und Erstellen der erforderlichen package.json im Terminal folgendes eingeben:
npm init 
Die einzelnen Key:Value Paare werden interaktiv abgefragt oder

npm init -y
Die einzelnen Key:Value Paare werden Default erstellt

Zum Fixieren, Festhalten des externen Moduls wird eine package-lock.json erstellt
Beispiel Modul prompt-Sync
npm install  prompt-sync --save
